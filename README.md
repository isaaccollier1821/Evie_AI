# Evie AI Assistant 🤖

Evie is a personal desktop AI assistant built with Python.

## Features

- 🧠 Local AI responses using Ollama
- 💬 Desktop GUI chat interface
- 🎤 Wake word activation
- 🔊 Text-to-speech responses
- 💾 Memory system
- ⚙️ PC automation commands
- 🔋 Battery monitoring
- 📸 Screenshot capture

## Built With

- Python
- Tkinter
- Ollama
- Llama 3.1
- Speech Recognition
- PyAudio
- psutil

## Current Version

Evie v0.6
